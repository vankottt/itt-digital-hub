# ITT Digital Hub plugin 1.0.0

First package. It contains one skill, ВиК Проектант, and the ViK MCP server.

The plugin name is ITT Digital Hub. Further skills can be added under `skills/` later. This release does not include the AI Act assistant.

The MCP endpoint declared in the package is `https://ittdigitalhub.org/api/mcp/vik`. It is live only after the website deployment that contains this route.

Privacy: https://ittdigitalhub.org/bg/privacy

A terms-of-service page is not published on the site, so the manifest does not invent one.

The ChatGPT product URL is configured later with `VIK_CHATGPT_DESTINATION_URL`.
