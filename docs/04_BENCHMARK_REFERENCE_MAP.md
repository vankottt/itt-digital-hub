# CIT WEBSITE — BENCHMARK REFERENCE MAP

## Purpose
This file prevents reference drift. Each benchmark has a specific job. No benchmark is a clone target.

## 1. Stanford HAI — visual north star
Use for:
- institutional confidence;
- editorial sophistication;
- whitespace;
- large typography;
- research-first presentation;
- human-centered visual tone;
- strong independent institute identity within a university context.
Do not copy:
- Stanford branding;
- Stanford red;
- exact page layouts;
- AI-centric information architecture as the sole CIT model.

## 2. Complexity Science Hub — homepage storytelling and visuals
Use for:
- translating complex research into clear human outcomes;
- research-topic taxonomy;
- data/interactive visualisation;
- researcher photography;
- linking science to public explanation.
Do not copy:
- its current content density; CIT V1 will have a much smaller corpus.

## 3. MIT IDSS — intellectual positioning
Use for:
- compressing a complex interdisciplinary idea into memorable conceptual territory;
- explaining intersections among systems, data, society and institutional behavior;
- clear framework diagrams.
Do not copy:
- MIT-specific academic restraint if it weakens the applied-project layer.

## 4. Dark Matter Labs — systems methodology visualization
Use for:
- system maps;
- architecture diagrams;
- visual relationships among capabilities, contexts and interventions;
- the feeling of a designed intellectual system.
Do not copy:
- dense philosophical language;
- dark/experimental aesthetic as the whole CIT visual identity.

## 5. The Alan Turing Institute — projects and institutional architecture
Use for:
- project detail structure;
- status and metadata;
- explaining science/methodology;
- applications, researchers, collaborators and publications;
- segmented partner journeys.
Do not copy:
- AI-specific project framing when CIT is addressing broader systems problems.

## 6. Cambridge Institute for Manufacturing — operating model
Use for:
- Research × Education × Knowledge Transfer relationship;
- audience routes for business, government, universities and students;
- applied university-to-industry logic.
Do not copy:
- Cambridge-specific institutional structure or terminology.

## 7. Oxford Internet Institute — navigation and insights
Use for:
- clean research/content architecture;
- research areas/groups/projects;
- reports, video, podcasts and policy/business engagement;
- people/content cross-linking.
Do not copy:
- scale of content categories before CIT has real content.

## 8. Connected Places Catapult — applied collaboration
Use for:
- project/demonstrator framing;
- stakeholder journeys;
- academics / enterprises / government / investors / SMEs style segmentation as inspiration.
Do not copy:
- categories that are irrelevant to CIT’s actual operating model.

## 9. VTT + Digital Catapult — technology transfer and demonstrators
Use for:
- research-to-pilot pathways;
- co-financed projects;
- innovation ecosystems;
- infrastructure/testbed access models;
- prototype → demonstrator → application logic.
Do not copy:
- service claims CIT cannot yet deliver.

## 10. Santa Fe Institute / IIASA / GovLab / Nesta
Use selectively for:
- owning an intellectual territory;
- systems-analysis credibility;
- public-institution intervention;
- mission and action-research framing.

## Master rule
HAI controls visual grammar.
The other benchmarks supply specific functional/content patterns.
All borrowed patterns must be translated into one original CIT design system

## ON-DEMAND BROWSING RULE
Do not comprehensively audit all reference sites during every build run. Start from the Build Pack. Open a live reference only when it can answer a concrete design/content question. Record any reference that materially influenced the selected CIT pattern in DESIGN_DECISIONS.md.

## FRANKENSTEIN PREVENTION RULE
Never implement a section in another benchmark's native visual style. Translate every borrowed functional/content pattern into the single selected CIT design language before implementation. Stanford HAI governs high-level visual grammar; the selected original CIT design system governs the actual implementation.
